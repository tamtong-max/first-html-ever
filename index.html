Basic HTML

What is HTML?

Welcome to the first step in web development. This section introduces the core purpose of Hypertext Markup Language. You will explore how HTML provides the foundation of a webpage, just like the structural framing of a house. By the end of this module, you will understand how HTML interacts with CSS and JavaScript to create a complete web experience.

🏠 The Web Design House Analogy

🧱 1. HTML (Foundation) Provides the essential layout and contents (texts, media, inputs). It is the bricks and mortar of the page.
🎨 2. CSS (Design) The styling layer. Think of it as the wall paint, wallpapers, and flooring that make the structure beautiful.
💡 3. JavaScript (Behavior) The functional layer. It is like placing smart furniture and working appliances inside the house.

⚙ Anatomy of an HTML Element

An HTML element is defined by a start tag, some content, and an end tag. Tags normally come in pairs.

<tagname> Element content </tagname>
Note: Self-closed tags like <br> and <img> do not need to be closed by a separate end tag.

Phân loại thẻ HTML

Trong HTML, các thẻ được chia làm hai loại chính: Thẻ thường (Normal Tags) yêu cầu thẻ đóng và Thẻ tự đóng (Self-closing Tags) hoạt động độc lập. Việc nắm rõ điều này giúp bạn tránh các lỗi cấu trúc phổ biến.

📚

Normal Tags (Thẻ đóng/mở)

Là những thẻ dùng để bao bọc nội dung bên trong (như văn bản, hoặc các thẻ khác). Chúng bắt buộc phải có <tag> và kết thúc bằng </tag>.

<h1>Đây là Tiêu đề</h1>
<p>Đây là một đoạn văn bản.</p>
<div>
  <span>Chứa thẻ khác bên trong</span>
</div>
⚡

Self-closing Tags (Thẻ tự đóng)

Là những thẻ không chứa nội dung văn bản bên trong. Chúng thực hiện một chức năng cụ thể ngay lập tức (như chèn ảnh, ngắt dòng, tạo ô nhập liệu).

<!-- Ngắt dòng -->
Dòng 1 <br> Dòng 2
<!-- Chèn hình ảnh -->
<img src="image.jpg" alt="Ảnh">
<!-- Ô nhập liệu -->
<input type="text">

Kiến thức ngoài lề: Nhúng Google Maps

Bạn có thể hiển thị nội dung từ một trang web khác bên trong trang web của mình bằng cách sử dụng thẻ <iframe>. Một trong những ứng dụng phổ biến nhất là nhúng Google Maps.

Cách nhúng Bản đồ bằng Iframe

<iframe
  src="https://www.google.com/maps/embed?pb=..."
  width="100%" height="350"
  style="border:0;" allowfullscreen="" loading="lazy">
</iframe>

*Mẹo: Truy cập Google Maps, tìm địa điểm của bạn, chọn nút "Share" (Chia sẻ) -> "Embed a map" (Nhúng bản đồ) và sao chép mã HTML để dán vào website.
